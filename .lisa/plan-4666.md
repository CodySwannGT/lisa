## Implementation and proof

1. Add one shipped verification controller. A local preflight resolves the
   installed package's real Antigravity destination and refuses an uncontained
   apply before spawning it. CLI absence never authorizes an apply.
2. Support genuine packaged applies in an explicitly inspected disposable
   Docker container. Copy inputs; never mount host paths or forward operator
   environment/credentials. Reject unsafe namespace, privilege and mount
   configurations before starting the container. Capture the image/container
   identity and package digest. This contains package installation, caches,
   Git configuration, detached reconciliation and vendor-owned paths too.
3. Capture declared host destinations before execution and compare them in
   failure paths as well as success. Unexpected changes stop execution and
   preserve current bytes privately; missing before-images remain unknown.
4. Run the actual installed bin.lisa with bootstrap and full apply. Require a
   full receipt and native allow/refuse cases against the emitted guard.
   Separate generated parity from native vendor activation, which is excluded.
5. Wire every generated Verify surface through the shared lifecycle contract.
   Root personally reviews code, security, behavior and scope. An independent
   verifier may execute empirical controls, without delegated code review.

probes passed. Docker CLI is installed; normal `docker desktop start` brought
