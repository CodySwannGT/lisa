# Roster Decision: evidence asset names (#4635)

This runtime exposes generic agents without a specialist-type selector. All roles use the inherited model and effort. The root lead owns tracker and Git delivery and performs a genuine final self-review, as the operator requested. No vendor review credit or extra human approval is invented.

- INCLUDE — generic read-only research equivalent — source, history, generation and harness research before implementation.
- INCLUDE — generic reproduction and implementation — preserve RED, repair the owning source and regenerate variants.
- INCLUDE — generic product review — all four acceptance scenarios and both validation journeys.
- INCLUDE — generic code review — naming, quoting, cleanup, upload failures and result verification.
- INCLUDE — generic quality verifier — independent regression, parity and native/public proof verification.
- INCLUDE — generic learner — assess durable learnings through the bounded contract; an empty capture is valid.
- EXCLUDE — vendor-specific specialist identities — not exposed by this runtime; generic agents must not impersonate them.
- EXCLUDE — browser, application-backend and cloud specialists — no affected surface requires these roles.

Roles may share a generic agent across sequential bounded tasks. Research precedes implementation; independent review roles run concurrently after implementation. Root does not treat an unavailable vendor review as completed work. Existing unrelated workers and worktrees remain owned by their current sessions.
